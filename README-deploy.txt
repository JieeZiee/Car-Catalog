Langkah cepat deploy dari HP (Netlify Drop):

1) Siapkan folder di HP dengan file:
   - index.html
   - styles.css
   - script.js
   - cars.json
   - (opsional) folder images/ jika ingin menyertakan file foto lokal

2) Ganti data:
   - Edit cars.json dengan data mobilmu (pakai aplikasi text editor di HP seperti "QuickEdit", "Acode", "Jota+", atau lewat catatan & paste).
   - Untuk gambar: lebih mudah upload foto ke folder images/ di dalam folder tersebut sebelum zip, atau gunakan link gambar publik (Imgur / imgbb / Google Drive public link) lalu masukkan URL di array images.

3) Buat file .zip:
   - Android: gunakan Files by Google atau aplikasi ZArchiver -> pilih semua file/folder -> Compress -> buat katalog.zip
   - iOS: buka app Files -> pilih folder -> Compress -> hasilkan katalog.zip

4) Deploy ke Netlify Drop:
   - Buka browser di HP: https://app.netlify.com/drop
   - Seret atau pilih file ZIP yang tadi dibuat (pada HP biasanya ada tombol 'Choose a site' atau 'Upload a folder' — pilih file).
   - Netlify otomatis akan mengupload dan menyediakan URL mis. https://calm-malasagna-xxxx.netlify.app
   - Catat URL dan bagikan ke customer.

5) Mengupdate listing:
   - Edit cars.json lalu ulangi compress -> upload Drop (bisa replace dengan nama zip berbeda). Atau gunakan akun Netlify + GitHub jika mau workflow update yang lebih canggih.

Tips penting:
- Gunakan nomor WhatsApp internasional tanpa tanda (+): contoh 6281234567890
- Jika ingin tiap mobil punya halaman langsung, situs mendukung link detail dengan hash: https://your-site.netlify.app#car-1
- Jika tidak ingin buat zip setiap update, kamu bisa belajar pakai GitHub + Netlify (kalau mau, saya bantu langkah berikutnya).
